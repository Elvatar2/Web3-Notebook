- Oracle Manipulation (Spot price, TWAP bypass)

## 📊 Learning Philosophy
Read → Understand → Implement → Break → Document → Repeat

I believe in **learning by doing**. Theory without practice is forgotten. Practice without documentation is lost. This repository is the bridge between the two.

### How I Study Each Topic
1. **Read** official docs and whitepapers
2. **Build** a minimal implementation from scratch
3. **Break** it intentionally (CTF-style)
4. **Fix** it using best practices
5. **Document** the entire process here
6. **Teach** others through writeups and threads
